# Skill-First Agent Architecture

> **Агент, который сначала использует навыки, а уже потом думает заново.**

Orion v0.39 вводит фундаментальное архитектурное решение: разделение
творческой работы (проектирование, написание кода) и механической работы
(запуск, выполнение). Первую делает ИИ (тратя токены), вторую — локальные
скрипты (без токенов, без интернета, без ИИ).

## Основной принцип

```
┌─────────────────────────────────────────────────┐
│          Пользовательская задача                 │
└──────────────────┬──────────────────────────────┘
                   ↓
         Есть готовый навык?
          ↓ Да           ↓ Нет
   Запустить локально    Можно создать навык?
   (orion run <name>)     ↓ Да          ↓ Нет
                          ИИ создаёт,    ИИ решает
                          тестирует,     напрямую
                          сохраняет      (тратя токены)
                          (orion forge
                           --save-as)
```

**Главное правило:**
> Не тратить токены там, где можно один раз создать процедуру.

## Два режима Orion

### Офлайн-режим: `orion run`

Пользователь (или cron) запускает готовый скрипт — задача решается без ИИ.

```bash
orion run new backup-db "Бэкап базы данных"
orion run edit backup-db        # написать логику
orion run backup-db             # запустить — 0 токенов
orion run schedule backup-db "0 3 * * *"  # cron ежедневно в 3:00
```

Каждый скрипт живёт в `~/.orion/scripts/<name>/`:
- `run.sh` — исполняемый файл
- `orion.json` — метаданные (описание, количество запусков, расписание)

### Онлайн-режим: ИИ создаёт навык через `--save-as`

ИИ получает промпт, проектирует решение, но вместо того чтобы запускать
его каждый раз за токены — сохраняет как автономный скрипт.

```bash
orion think "автоматически сортировать скриншоты по дате"
orion draft screenshots-sorter
orion forge screenshots-sorter --save-as sort-screenshots
# Дальше скрипт живёт сам:
orion run sort-screenshots      # без токенов!
```

## Классификация задач

Orion определяет 5 категорий задач. Классификатор встроен в `orion think`
через prompt guard и deriveTasks.

### Категория 1: Полностью локальные детерминированные
Файловые операции, архивация, конвертация форматов, бэкапы, сборка,
запуск тестов.

→ **Всегда скрипт.** ИИ создаёт один раз.

### Категория 2: Локальные с небольшой неопределённостью
Парсинг PDF-счетов, извлечение данных из таблиц, обработка логов.

→ **Скрипт + ИИ для исключений.** 95% через скрипт, 5% через ИИ.

### Категория 3: Внешние API и сетевые
Курс валют, Telegram-боты, трекеры задач, скачивание файлов.

→ **Скрипт** при стабильном API. Ключи в переменных окружения.

### Категория 4: Динамичные веб-задачи
Скрин-скрапинг, мониторинг цен, автозаполнение форм.

→ **Скрипт + авто-починка ИИ.** Скрипт ломается → ИИ чинит.

### Категория 5: Творческие/аналитические/открытые
Написание текста, исследование, сравнение идей, оценка рисков.

→ **Всегда ИИ.** Не автоматизируется.

## Экономическая модель

```yaml
cost_metrics:
  creation_tokens: 43000      # токены на создание навыка
  average_repair_tokens: 2000 # токены на починку
  runs: 120                   # запусков с момента создания
  tokens_saved_per_run: 900   # экономия на каждом запуске
  total_tokens_saved: 108000  # общая экономия
  net_tokens_saved: 63000     # чистая экономия (минус создание и ремонт)
  roi: positive
```

Система отслеживает `runCount` в `orion.json` каждого скрипта.
Будущая версия `orion metrics` покажет ROI по каждому навыку.

## Песочница и безопасность

Скрипты запускаются с ограничениями:
- отдельная рабочая директория `~/.orion/scripts/<name>/`
- таймаут 30 секунд
- запрет `sudo`, `rm -rf /` (hazard gate из shield)
- переменная `ORION_RUN_NAME` для идентификации
- логирование в `orion.json` (runCount, lastRun)

## Реестр навыков

Каждый навык — это оформленный объект в `~/.orion/scripts/<name>/orion.json`:

```json
{
  "name": "organize-screenshots",
  "description": "Сортировка скриншотов по дате",
  "runtime": "bash",
  "created": "2026-08-11T20:00:00Z",
  "lastRun": "2026-08-12T08:30:00Z",
  "runCount": 42,
  "schedule": "0 */6 * * *",
  "sourceChange": "screenshots-sorter"
}
```

## Сравнение с аналогами

| Система | Создание навыка | Запуск | Токены |
|---------|:---:|:---:|:---:|
| ChatGPT Actions | Через UI | Сервер OpenAI | Каждый раз |
| Claude Artifacts | В чате | Только в чате | Каждый раз |
| npm scripts | Руками | Локально | 0 |
| **Orion run** | **ИИ + shield** | **Локально / cron** | **0** |

Orion — единственная система, где ИИ **создаёт и верифицирует** навык через
полный цикл think→draft→forge→shield, а запускается навык **локально и
бесплатно**.
