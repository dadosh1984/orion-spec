# Spec: core

## Purpose
Сделать веб-дашборд Orion (`orion serve`) живым и информативным: добавить авто-обновление и новые панели метрик, которые Orion уже умеет считать, сохранив жёсткие ограничения безопасности (loopback-only, XSS-экранирование, без мутаций).

## Requirement
RFC 2119 keywords: MUST / SHOULD / MAY.

### Реальное время
- MUST: дашборд авто-обновляется периодически (polling на ванильном JS, без внешних зависимостей), не требуя клика по Refresh. Интервал ~5 секунд.
- MUST: остаётся ручная кнопка Refresh.

### Новые метрики
- MUST: панель «Economy» — экономия токенов (savedTokens, savedBytes, entries) + разбивка по проектам (byProject).
- MUST: панель «Budget» — бюджет по namespace кэша (bytes, tokens, share) с визуальной шкалой.
- MUST: панель «Debt» — количество открытых записей отложенного долга.
- MUST: панель «Lessons» — число уроков самокоррекции и дата последнего.
- MUST: в списке изменений показывать прогресс задач (done/total) из tasks.md — не только флаг result.

### API
- MUST: новый эндпоинт `/api/metrics`, возвращающий `{version, economy, budget, debt, lessons}`.
- MUST: `/api/changes` дополнительно отдаёт `tasks: {done, total} | null` на каждое изменение.
- MUST: новые данные отдаются без мутаций состояния (только GET), `Cache-Control: no-store`.

### Безопасность (жёсткие пределы)
- MUST: сервер по умолчанию слушает только `127.0.0.1` (loopback) — кэш с полными значениями не должен быть доступен из сети без явного `--host`.
- MUST: весь динамический текст, рендеримый в HTML (названия изменений, цели, имена проектов, namespace), экранируется от XSS.
- MUST: существующий эндпоинт `/api/cache`, отдающий полные значения кэша, остаётся доступен и по-прежнему означает, что дашборд нельзя открывать в сеть без авторизации.

## Acceptance criteria
- [ ] `dashboardHtml` содержит авто-refresh timer и новые панели (Economy, Budget, Debt, Lessons) и прогресс задач.
- [ ] `/api/metrics` отдаёт economy, budget, debt, lessons; поля корректного типа.
- [ ] `/api/changes` включает `tasks.done/total` на основе tasks.md.
- [ ] Подключение в тестах к `/` и `/api/metrics` возвращает 200 и экранированный валидный контент.
- [ ] Тесты покрывают новое поведение и XSS-экранирование.
