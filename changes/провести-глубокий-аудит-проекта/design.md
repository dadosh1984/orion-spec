# Дизайн — Глубокий аудит и модернизация Orion v0.36 → v0.37

## Обзор

Шесть фаз улучшений на основе детерминированного анализа кодовой базы
(13,252 строк исходного кода, 63 тестовых файла, 595 тестов). Каждая фаза
закрывает конкретную категорию проблем, найденных аудитом.

## Фаза 2 — Дедупликация

- `humanBytes()` — две идентичные реализации в `serve.ts` и `file.ts`
- `driftOf()` — логика проверки drift в `serve.ts` (для dashboard) 
  дублирует `review/handler.ts`; выделить в `core/drift.ts`
- 38 файлов в `src/tasks/`, часть из которых <100 байт и не имеют тестов

## Фаза 3 — Новые команды

- `orion config` — просмотр и редактирование конфигурации без ручного
  редактирования JSON
- `orion clean` — очистка кэша и артефактов одной командой
- `orion completion` — shell-автодополнение для bash/zsh/powershell
- `orion status --watch` — live-мониторинг изменений

## Фаза 4 — Dashboard

- WebSocket (через встроенный `node:http` upgrade) для push-обновлений
- Переключатель тем (тёмная/светлая) с сохранением в localStorage
- Sparkline и bar-chart в `orion metrics` для наглядности

## Фаза 5 — Интерактивный shell

- `orion shell` — REPL с readline, историей и автодополнением
- Progress bar через сигналы MCP progress token
- Цветовая дифференциация severity (PASS/WARN/FAIL)

## Фаза 6 — Производительность и полировка

- Асинхронные файловые операции в горячих путях
- `orion profile set` — ручная установка полей профиля
- Обновление документации
