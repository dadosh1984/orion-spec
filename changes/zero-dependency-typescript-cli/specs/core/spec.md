# Spec: core

## Назначение
Создать zero-dependency TypeScript CLI safe-env для безопасного шифрования и дешифрования .env файлов с мастер-паролем, командами encrypt/decrypt/add/list, защитой от path traversal и TDD-покрытием тестами vitest.

## Область

- В области: указанная возможность, поставляется тест-первой.
- Вне области: всё, что не заявлено в предложении.
