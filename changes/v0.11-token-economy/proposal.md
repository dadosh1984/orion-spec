# Proposal — v0.11-token-economy

**Goal:** v0.11 Token Economy — собственная система экономии токенов для Orion, улучшенный аналог rtk без копирования. Сжатие вывода команд в ядре: vitest/eslint/tsc только ошибки + счётчик, git status/diff/log компактно, ls, grep/rg, pnpm install. Fail-safe при ошибке фильтра — исходный вывод, --verbose для полного. Агент-агностичность: все 35+ агентов через MCP получают сжатые выводы + новый MCP-инструмент compress для произвольного bash-вывода. orion metrics: секция token economy с честной оценкой байты/4. next: оценка стоимости вариантов, дешёвые первыми. Кеш повторных выводов по хешу. Платформа: node >=22, CLI + MCP stdio. Ограничения: ноль зависимостей, без новых CLI-команд, все существующие тесты зелёные, честность (байты/4 — оценка). Бюджет: одна сессия, точечные прогоны тестов, минимум полных CI.

- Platform: node >= 22.12, CLI + MCP (stdio), все агенты (35+ моделей) через MCP
- Constraints: ноль зависимостей; без новых CLI-команд (кроме исключительных); все 213 существующих тестов зелёные; честность: байты/4 — только оценка; fail-safe при ошибке фильтра; RU/EN обрезка
- Budget: одна сессия; точечные vitest-прогоны вместо полного CI на каждом шаге; цель — экономный конвейер
