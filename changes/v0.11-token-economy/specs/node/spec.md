# Spec: node

## Purpose

Собственная, zero-dependency система экономии токенов в ядре Orion: агент-агностичное
сжатие вывода команд до того, как его прочитает LLM-агент; честные метрики экономии;
cost-осведомлённый помощник `next`. Не копия rtk — свой чистый TS-вариант, встроенный
в существующие поверхности (MCP, metrics, next), без новых CLI-команд.

## Acceptance criteria

### Компрессор `src/core/compress.ts`
- [x] `compress(cmd, stdout, stderr)` возвращает `{out, savedBytes, savedPct, matched}`; `matched: false` при отсутствии правила.
- [x] vitest: при всех зелёных — одна строка «N passed, M failed» + имена файлов; при провалах — точные строки с file/name/assertion; счётчик сэкономленных байт > 0 на реальном выводе vitest.
- [x] eslint/tsc: только строки с ошибками (file:line:col + текст), прогресс/счётчики вырезаны.
- [x] git status → компактная группировка по состоянию (1 строка на группу + счётчики); git log → «hash subject» на строку; git diff → урезанные хунки без заголовков; ls → компактный список со счётчиками каталогов; grep/rg → группировка по файлам, длинные строки обрезаны; pnpm install → одна строка итога.
- [x] Fail-safe: фильтр бросил исключение или вход не распознан → исходный вывод нетронут, `matched: false`, никакого throw наружу.
- [x] Честность: в выводе при сжатии присутствует оговорка «≈ bytes/4 токенов — оценка, без токенизатора»; `verbose: true` → исходный вывод + строка «[orion: N bytes saved]».
- [x] RU/EN-обрезка: строка с кириллицей обрезается корректно по ширине, хвост помечен «… [+N ch]».

### MCP-инструмент `compress` (агент-агностично)
- [x] Новый инструмент в `src/core/mcp.ts`: вход `{command, output, verbose?}`, выход JSON `{out, savedBytes, savedPct, matched, cached}`.
- [x] Повторный вызов с тем же входом (в течение TTL) → `cached: true`, фильтр не выполняется повторно (кеш по хешу через OrionTrack).
- [x] Нет новой CLI-команды — только MCP-инструмент и библиотека.

### Компактный рендер в существующих поверхностях
- [x] shield test-шаг и forge отображают вывод тестов сжато (только ошибки + счётчик) через компрессор; при отсутствии правила — исходный вывод.

### `orion metrics` — секция «token economy»
- [x] metrics выводит секцию: сэкономлено байт/токенов по namespace кеша (оценка bytes/4 с оговоркой), количество записей.
- [x] Аппенд-лог `~/.orion/economy.json`: каждая операция сжатия/кеш-попадания дописывает `{ts, cmd, inBytes, outBytes, cached}` — реальные измеренные данные.

### Cost-осведомлённый `next`
- [x] Каждый вариант `alternatives` получает `estimatedCost` (≈ токенов, оценка по байтам артефактов, помечена «~»).
- [x] Варианты сортируются по `estimatedCost` по возрастанию (дешёвые первыми); сортировка не ломает существующие поля (`next`, `summary`, `phase`).

## Non-goals
- Не добавляем CLI-команды; не эмулируем tokenizer; не трогаем кеш shield/track, кроме переиспользования OrionTrack.
