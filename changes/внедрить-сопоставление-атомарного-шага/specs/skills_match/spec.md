# Spec: matchSkill

## Purpose
Сопоставлять атомарный шаг задачи со skill-реестром поэтапно, начиная с
дешёвого варианта без ML: BM25/TF-IDF скоринг по нормализованной строке
действия + описанию + тегам (self-contained, без внешних сервисов),
домен-фильтр до матчинга, консервативные пороги, миss-лог с первого дня,
промоушен в skill только с подтверждением пользователя и replay на
исторических входах/выходах.

## Scope

- In scope: `src/core/skillsMatch.ts` (BM25 + пороги + домен-фильтр),
  `src/core/skillMissLog.ts` (миss-лог), расширение `RunManifest` полями
  `tags` / `domain` / `environmentFingerprint`, подтверждаемый промоушен
  с replay, метрика экономии.
- Out of scope: эмбеддинги (фаза 3, только при сигнале из логов),
  полноценная инвалидация по отпечатку окружения (фаза 4).

## Acceptance criteria
- [x] BM25: точное совпадение > перефразировки; IDF из каталога scripts/
- [x] домен-фильтр до скоринга — нет кросс-доменных ложных совпадений
- [x] пороги: USE_SKILL (уверен) / CANDIDATES (пограничный, LLM-верификация) / NO_MATCH
- [x] миss-лог пишется для каждого NO_MATCH и пограничного случая
- [x] промоушен-кандидаты из лога (`orion run match --promote`)
- [ ] `orion run --approve` (интерактивное подтверждение + replay перед регистрацией) — следующая итерация
- [x] отпечаток окружения пишется (инвалидация — Фаза 4)
- [ ] метрика steps_via_skill vs steps_via_llm — счётчик следующей итерацией
