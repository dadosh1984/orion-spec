# Spec: zero_external_dependencies_backward_comp

## Назначение
Создать навык (skill/команду) "orion run" для автономного выполнения задач через локальные скрипты без ИИ и без интернета. Суть: пользователь описывает задачу один раз, orion превращает её в локальный скрипт (bash/node/python). Скрипт сохраняется в ~/.orion/scripts/<task-slug>/ и может быть запущен в любой момент через `orion run <task>` — без токенов, без интернета, без ИИ. Песочница: можно задать cron-расписание для периодического запуска. Два режима работы Orion после этого изменения: 1. Офлайн-режим (скрипты): `orion run` — запускает готовый локальный скрипт. Пользователь (или cron) дёргает скрипт — задача решается без ИИ. 2. Онлайн-режим (ИИ-агент): ИИ получает промпт, но вместо того чтобы решать задачу самому (тратя токены на каждый чих), он генерирует скрипт через `orion think → draft → forge → shield` и сохраняет его как runnable script. Дальнейшие запуски — через `orion run`, без токенов. Ключевая экономия: ИИ платит токенами ОДИН раз за создание скрипта, а запускается скрипт бесконечно бесплатно. Разделение: творческая работа (проектирование) — ИИ; механическая работа (запуск) — скрипт. Что нужно: - `orion run <name>` — запустить сохранённый скрипт - `orion run list` — список сохранённых скриптов - `orion run new <name>` — интерактивное создание нового скрипта - `orion run schedule <name> <cron>` — настроить cron-расписание - `orion run unschedule <name>` — убрать из расписания - `~/.orion/scripts/<name>/run.sh` — исполняемый скрипт - `~/.orion/scripts/<name>/orion.json` — метаданные (описание, создан, последний запуск) - Интеграция с существующим workflow: `orion forge` может сохранять результат как runnable script через `--save-as <name>` — Node.js >=22.12.0, zero-dependency, CLI, Linux/macOS/Windows (cron только на linux/mac)
