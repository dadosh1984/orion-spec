# Дизайн — провести-глубокий-честный-аудит (v0.47)

## Обзор
Аудит проекта v0.46 выявил до 20 кардинальных улучшений по 5 фазам.
Реализация ведётся задача за задачей через цикл RED-GREEN-REFACTOR;
каждая задача из tasks.md становится одним тест-управляемым юнитом.

## Модули (зоны изменений)
- `src/core/runtime.ts`, `src/cli/runCmd.ts` — Windows-совместимость скриптов
- `src/utils/file.ts`, `src/utils/format.ts`, `src/tasks/*` — дубли и мёртвый код
- `src/utils/term.ts`, `src/cli/commands.ts`, `src/utils/format` — user-friendly вывод
- `src/core/*`, `src/cli/runCmd.ts`, `src/core/compress.ts` — производительность
- `src/core/track.ts`, `src/cli/configCmd.ts`, уроки, README — функциональность

## Ключевые инварианты
- Zero runtime-зависимостей, backward compatibility.
- Все выводы в терминал — человекочитаемые (не сырой JSON); флаг `--json` — опция.
- Токен-экономия не ухудшается: новый код пишется так же экономно по контексту.
- Русский язык пользовательского вывода допустим (проект адаптируется под профиль).

## Верификация
Задача сдана, только когда зелёные:
- [ ] lint (pnpm lint)
- [ ] типы (tsc --noEmit)
- [ ] юнит-тесты (pnpm test) — после фикса must быть 663+ без регрессий
