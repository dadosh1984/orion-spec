# Proposal — v0.12-self-correction

**Goal:** v0.12 Self-correction & learning — Orion должен быть самообучающимся и уметь исправлять собственные ошибки. Если в любой из последовательностей (think-draft-forge-shield-out) возникает ошибка или сомнение со стороны Orion, Orion должен честно признать это, вернуться к пункту think с новой исправленной задачей и исправить свои ошибки. Механика: хранилище уроков lessons в ~/.orion/lessons.json ноль зависимостей — при сбое shield-out-forge-tdd Orion записывает запись changeId step error cause fix ts; next при ошибке или сомнении возвращает маршрут вернуться в think с сгенерированным исправленным промптом; think сверяет новую задачу с прошлыми уроками самообучение между проектами; MCP-инструмент lessons_list для агентов. Платформа node 22 CLI и MCP stdio. Ограничения ноль зависимостей без новых CLI-команд все существующие тесты зелёные честность ошибка признаётся не маскируется. Бюджет одна сессия точечные прогоны тестов.

- Platform: node
- Constraints: ноль зависимостей; без новых CLI-команд (кроме исключительных — track lessons — согласовать с гидом); все 241 существующих тестов зелёные; честность: ошибка признаётся и исправляется, не маскируется; RU/EN
- Budget: одна сессия; точечные vitest-прогоны; демо цикла: сбой → урок → возврат в think с исправленной задачей
