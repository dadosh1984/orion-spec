# Orion Implementation Plan – Steps 81‑100

**4️⃣ Skills (think, draft, forge, shield)**
81. В `src/skills/think/handler.ts` реализовать `export async function think(prompt:string):Promise<Proposal>`: выводит 3‑4 вопросов через `readline`, собирает ответы в объект `Proposal {title, goal, platform, constraints, budget}`.
82. В `think/` добавить `templates.ts` – массив вопросов `{msg:string,key:string}` и утилиту `askQuestion(msg)`.
83. Сохранять полученный `Proposal` в файл `changes/<title>/proposal.json` через `OrionTrack.store('proposal:'+title, JSON.stringify(proposal))`.
84. В `src/skills/draft/handler.ts` читать `Proposal`, генерировать артефакты:
   - `proposal.md`
   - `specs/<capability>/spec.md` (пустой шаблон)
   - `design.md`
   - `tasks.md` (чек‑лист с `- [ ]`).
85. Сохранять артефакты в каталог `changes/<title>/`.
86. В `src/skills/forge/handler.ts` читать `tasks.md`, для каждой строки `- [ ] <desc>`:
   a) генерировать slug (`slugify(desc)`).
   b) вызывать `orion tdd start <slug>`.
   c) ждать пользовательский код (через файл `snippet.ts` или stdin).
   d) `orion tdd implement <slug> <snippet>`.
   e) `orion tdd refactor <slug>`.
   f) после PASS менять чек‑лист на `- [x]`.
87. После каждой завершённой задачи запись в кеш: `track.store('task:'+slug,'DONE')`.
88. В `src/skills/shield/handler.ts` реализовать последовательный запуск guard‑rails:
   1) **lint** (`pnpm lint`).
   2) **type‑check** (`pnpm exec tsc --noEmit`).
   3) **unit‑tests** (`pnpm test`).
   4) **drift‑check** – сравнение кода со `specs/*` через `@babel/parser` (построить AST, сравнить). 
   5) **security‑scan** – поиск `eval`, `new Function`, `process.env.*` в коде.
89. Каждый шаг проверять кэш: `if(await track.load('shield:'+step)) skip; else run && store PASS`.
90. После всех шагов собрать `GuardReport` (JSON + markdown) в `reports/<change>/guard-report.md`.
91. Добавить в `src/cli/commands.ts` команды: `think <prompt>`, `draft <proposal-id>`, `forge <draft-id>`, `shield <change-id>`.
92. Написать unit‑тесты для каждого хэндлера (`think.test.ts`, `draft.test.ts`, `forge.test.ts`, `shield.test.ts`) – использовать mock‑readline и mock‑fs.
93. Добавить e2e‑тест `workflow.e2e.test.ts` – от `think` до `shield`, проверяя, что `guard-report.md` существует и содержит `PASS`.
94. Обновить `README.md` раздел **Full workflow** с блок‑схемой и примером команд.
95. Добавить типы `Proposal`, `ArtifactSet`, `GuardReport` в `src/type.ts`.
96. Обеспечить, что `forge.handler` использует `OrionTrack` для проверки статуса задач.
97. Добавить CLI‑флаг `--no-cache` во все команды (пропускает проверку кэша).
98. Добавить в `src/utils/file.ts` функцию `writeJson(file,obj)` и `readJson(file)` для удобства.
99. Добавить в `package.json` скрипт `"metrics":"node dist/cli/index.js metrics"` (будет реализовано позже).
100. Закоммитить всю реализованную функциональность, добавить тег `v0.1.0`.
