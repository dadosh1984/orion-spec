# Orion Implementation Plan – Steps 61‑80

**3️⃣ RED‑GREEN‑REFACTOR (orion‑tdd‑core)**
61. В `src/core/tddCore.ts` объявить `enum State { RED, GREEN, REFACTOR }`.
62. Создать класс `TddEngine` с полями `task:string`, `state:State=State.RED`, `completed:boolean=false`.
63. Метод `generateTest()` – читает шаблон из `src/config/orionTdd.json`, подставляет название задачи, пишет `tests/${task}.test.ts`.
64. Метод `runTest()` – исполняет `pnpm test --filter ${task}` через `child_process.exec`, возвращает `true`/`false`.
65. Метод `applyCode(snippet:string)` – записывает `src/tasks/${task}.ts`.
66. Метод `transition()` – если `state===RED` и тест падает – остаётся RED; если тест проходит – ставит `state=GREEN`.
67. Метод `refactor()` – запускает `pnpm lint --fix` и `pnpm format`.
68. Метод `finalize()` – ставит `completed=true`, сохраняет запись `track.store('tdd:'+task, 'DONE')`.
69. В `src/cli/commands.ts` добавить под‑команды:
   - `tdd start <task>` → создает `TddEngine`, генерирует тест.
   - `tdd implement <task> <path-to-snippet>` → применяет код, вызывая `transition`.
   - `tdd refactor <task>` → вызывает `refactor`.
70. Добавить флаг `--watch` (fs.watch) – автоматический `runTest` после каждой правки.
71. Написать unit‑тест `tddCore.test.ts` (симулировать задачу `add`, проверять переходы).
72. Добавить e2e‑тест `cli/tdd.e2e.test.ts` (CLI команды, проверка статуса через `track`).
73. Добавить тип `TddConfig` в `src/type.ts` и пример в `src/config/orionTdd.json`.
74. Обновить `README.md` секцию **TDD‑engine** с пошаговым примером.
75. Добавить в `package.json` скрипт `"tdd":"node dist/cli/index.js tdd"` для быстрого тестирования.
76. В `src/cli/index.ts` импортировать `TddEngine` и зарегистрировать команды.
77. Убедиться, что `pnpm run test` покрывает как минимум 80 % кода TDD‑модуля.
78. Добавить в CI шаг `npm run test --coverage` и проверять покрытие >=80 %.
79. Добавить в `orionTrack.json` запись о хранении статуса TDD (`tdd:<task>`).
80. Добавить в `README.md` **пример** полного TDD‑цикла для задачи `calcSum`.
